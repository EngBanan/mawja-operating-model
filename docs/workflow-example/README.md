# Workflow example

This example follows an atomic-save task in a fictional command-line notes app. It covers the task prompt, implementation report and independent review.

For role responsibilities and the reading path, see [Start here](../00-foreword.md). Use [Terms](../00-terms.md) when reviewing the evidence below.

The app stores notes in one JSON file. Hashes, measurements and costs are sample values.

| File | What it shows |
|---|---|
| [01 · The prompt](01-the-prompt.md) | A shortened completed prompt with requirements, measurements and acceptance checks |
| [02 · The report](02-the-report.md) | The implementation report, including unmeasured behavior |
| [03 · The verification](03-the-verification.md) | Automated checks, independent mutation, claim verification and merge |

Read the files in order. The notes app is not included in this repository. To create and run a project, use the [calculator examples](../../examples/README.md).
