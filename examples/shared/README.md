# Shared example files

The [project creator](../create.mjs) adds these files to every generated language example:

| File | Purpose |
|---|---|
| [PROJECT.md](PROJECT.md) | Rules for implementing and reviewing calculator changes |
| [DECISIONS.md](DECISIONS.md) | Decision log |
| [PROGRESS/TECHNICAL_DEBT.md](PROGRESS/TECHNICAL_DEBT.md) | Open work and its acceptance criteria |
| [.gitignore](.gitignore) | Files excluded from the generated project's Git history |

Each language directory supplies its own application, tests, configuration and project README. To create a project, follow the [example setup](../README.md).
